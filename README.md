## Oilscope: Nigeria's oil and gas, mapped
**[oilscope.net](https://oilscope.net)** is a live map of Nigeria's oil and gas sector that I designed and built end to end.

- **Pipeline:** a daily Python job gathers open data on fields, terminals and pipelines, and cross-checks each site against independent sources
- **Flaring:** satellite gas-flare detections matched to the nearest oil and gas site
- **Spills and production:** twenty years of oil spill reports and monthly production by terminal
- **Product:** a fast, mobile-friendly map with charts, downloads, live chat and automated data refreshes, on a serverless backend

The code is in a private repository because it includes licensed data. I'm happy to walk through the architecture on a call.
